# Control de calidad previo a la entrega

- [ ] Existe consentimiento para usar los datos entregados.
- [ ] No hay credenciales, cuentas completas ni datos personales innecesarios.
- [ ] Se especifica período, moneda y origen de la información.
- [ ] No hay duplicados evidentes ni movimientos sin clasificar sin advertencia.
- [ ] Los totales concilian con las filas de origen.
- [ ] El saldo usa la fórmula declarada y no se confunde con dinero en banco.
- [ ] Los hallazgos están respaldados por datos.
- [ ] Las recomendaciones son específicas y no prometen retornos.
- [ ] Se señalan faltantes, incertidumbre y límites del servicio.
- [ ] El cliente recibe el entregable acordado y una explicación clara.
